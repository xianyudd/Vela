# Vela v1.0.0

Vela 的第一个正式版本，提供 Windows 11 / WSL2 下已通过真实物理压缩验收的 VHDX 压缩工作流。

## 本版内容

- 多实例发现、实例选择、目标锁定与档案管理。
- 只读预检：映射、VHDX、运行状态、日志和阻断项。
- 压缩影响评估，展示当前体积、预计体积和具体的预计可回收空间。
- 两次 `Y` 确认，第二次确认页显示锁定目标与影响范围。
- UAC worker、单 worker gate、目标二次校验和 TUI 内日志归档。
- 目标 VHDX 被占用时的诚实验证与故障锁定保护。
- DiskPart 压缩过程的实时进度写入运行日志。
- self-contained `win-x64` 单文件发布物。

## 相对 v0.1.0-preview.1 的改进

- 安全加固：以应用清单提升权限，而非 `runas` 动词；验证 Windows 实际渲染的描述符而非自述。
- 可靠性：紧凑锁在 worker 崩溃后仍可回收；压缩成功未经证实即失败关闭。
- 日志与排查：启动流程优化、运行步骤失败原因记录、压缩实时进度。
- TUI：锁定目标与档案配对展示、状态徽章与更精细的进度条、日志选择走可信状态。
- 交付：单文件安装脚本与 VS 启动配置。

## 下载与校验

下载 Release 资产中的 `Vela-v1.0.0-win-x64.exe`，并使用同目录的 `SHA256SUMS.txt` 校验：

```powershell
Get-FileHash .\Vela-v1.0.0-win-x64.exe -Algorithm SHA256
```

## 验收状态

已在一台 Win11 上对锁定目标完成真实物理压缩人工验收，确认压缩成功；Release TUI 素材全部来自真实构建。
